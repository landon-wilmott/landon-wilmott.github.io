Enterprise Virtualization, K3s Kubernetes & Security Homelab (IaC)

Alongside my hardware and circuit engineering work in EC EN 340, I architected and maintain a multi-node Proxmox VE & 3-Node K3s Kubernetes environment automated with Ansible Infrastructure as Code (IaC), CrowdSec Distributed IPS, and Longhorn + Cloudflare R2 disaster recovery.

Proxmox VE & LXC 3-Node K3s Kubernetes Ansible IaC CrowdSec IPS Longhorn + Cloudflare R2 C++ Telemetry

Production-Grade Security & Infrastructure Highlights

  • Distributed Intrusion Prevention (CrowdSec LAPI + Bouncers): Wrote Ansible playbooks (deploy_crowdsec_agents.yml) using delegate_to orchestration to automatically register Linux nodes with a central CrowdSec LAPI "Brain" and deploy iptables firewall bouncers.
  • Zero-Trust Host Hardening (harden_all.yml): Automated default-deny UFW firewalls dynamically populated from inventory port variables, SSH ed25519 key-only lockdown restricted to a Tailscale management IP, and Fail2Ban jails.
  • 3-Node K3s Cluster, Longhorn Storage & Cloud DR: Deployed high-availability workloads across 3 nodes (i5-server, lenovo-server, pi-server) with Longhorn distributed block storage and automated 2:00 AM daily backups to Cloudflare R2, plus Traefik ACME DNS-01 TLS and Cloudflare Tunnels.
  • >50% Resource Consolidation & C++ Monitoring: Migrated heavy VMs to lightweight Proxmox LXC containers (cutting RAM/CPU usage by >50%) and built a custom C++ daemon to poll Proxmox REST API health metrics and alert via Discord webhooks.
